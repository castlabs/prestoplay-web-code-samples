Custom DRM environment

Example of a custom DRM environment whose license modifiers add authorization to each license request and unwrap a license that the server returns wrapped in JSON.

Setup required: The modifiers talk to a DRMtoday license server. Enter your DRMtoday license server, the custom data of your merchant, and a stream protected with keys from that account, then load the stream.

Base URL of your DRMtoday license server, without a path.
