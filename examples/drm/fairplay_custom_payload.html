Custom FairPlay key request

Example of FairPlay license modifiers that build the key request with a content ID from your own data instead of the playlist, send it to a license server in a JSON body, and unwrap the license from a JSON response. The log shows each modifier as it runs.

Setup required: FairPlay only works in Safari. The modifiers expect the JSON license API described in examples/drm/fairplay_custom_payload.js; adapt them to your license server. Enter its URLs, the content ID, and a FairPlay-protected HLS stream, then load the stream.

The ID your license server knows the asset by, sent as releasePid.

Value of the Authorization header on license requests.
