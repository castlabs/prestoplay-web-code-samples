Multiple DRM environments

Example of one player that plays assets protected by two different DRM providers. Each asset carries its own DRM configuration: asset 1 gets its licenses from DRMtoday, asset 2 from another license server that authorizes requests with HTTP headers.

Setup required: Enter a protected stream and its DRM setup for each asset, then switch between them with the play buttons.

    Asset 1: DRMtoday

    Asset 2: other license server

    Optional. Sent with every license request.
