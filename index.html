PRESTOplay Web Code Samples

  • Basic example — Load and play a stream with HLS/DASH support
  • React integration — React player component with play/pause, seek bar, and fullscreen

Player

  • Player configuration — Autoplay and the browser autoplay policy, start time, volume, buffering goals, and retries
  • Player surface — Custom container element, an overlay on the video, and style overrides
  • Simple UI — Minimal custom UI with a poster image and a big play button
  • Smart TV — Suspend and resume handling, a memory-friendly configuration, and remote control keys for Tizen and webOS

DRM

  • DRMtoday playback — DRM-protected DASH playback with licenses from DRMtoday
  • DRMtoday Onboard — DRM-protected DASH playback with licenses from DRMtoday Onboard, the offline DRMtoday for private networks
  • Custom license server — Widevine, PlayReady, and FairPlay license servers that authorize requests with HTTP headers
  • Persistent license — Store a DRM license on the device, reuse it, and remove it
  • Custom DRM environment — Custom DRM environment with license modifiers that authorize requests and unwrap JSON-wrapped licenses
  • Custom FairPlay key request — FairPlay license modifiers that build the key request with your own content ID and talk to a JSON license API
  • Multiple DRM environments — One player that switches between assets whose licenses come from DRMtoday and from another license server
  • Verimatrix VCAS Ultra — DRM-protected DASH or HLS playback with Widevine, PlayReady, and FairPlay licenses from Verimatrix VCAS Ultra

Live

  • Low-latency live — Live DASH playback close to the live edge with live edge chasing
  • Live delay — Control how far behind the live edge DASH and HLS live streams play
  • Fast channel zapping — Switch between live channels quickly with the experimental McPlaylist, which preloads the neighboring channels

Playlist

  • Playlist — Play DASH and HLS items back-to-back with previous/next controls
  • Seamless playlist — Continuous back-to-back playback with the experimental ScPlaylist, with timeline windows, timeline modes, cropping, and cues

Plugins

  • Custom plugin — Stats overlay plugin that shows the plugin lifecycle

Advertising

  • Google IMA ads — Client-side pre-, mid-, and post-roll ads with an ad event log
  • Ad UI and skipping — Custom player UI during ads: ad label with countdown, play/pause, seek controls disabled during ads, and a skip button
  • SIMID interactive ads — L-banner overlay creatives at set times of the content, with SIMID events

360° video

  • 360° video — Equirectangular 360° playback with mouse and touch dragging, and camera control from code

Thumbnails

  • DASH embedded thumbnails — Thumbnails declared in the DASH manifest, no configuration needed
  • Single-image thumbnails — One image per thumbnail from a URL template (SINGLE mode)
  • Grid thumbnails — Sprite sheets with many thumbnails each, from a URL template (GRID mode)
  • WebVTT thumbnails — A WebVTT file that maps time ranges to sprite sheet regions (WEBVTT mode)
  • BIF thumbnails — A single binary BIF file, the Roku thumbnail format (BIF mode)

Tracks

  • Audio and subtitle tracks — Initial language selection with fallbacks, and switching audio, subtitles, and video quality

Subtitles

  • Subtitle text styling — Configure subtitle font, color, background, and edge styling
  • SRT subtitles — Side-load SubRip (SRT) subtitles for a DASH stream
  • WebVTT and TTML subtitles — Side-load WebVTT and TTML subtitles for DASH and HLS streams

Networking

  • Request and response modifiers — Add auth headers and query parameters, and rewrite the manifest
  • CMCD — Send Common Media Client Data (CMCD) with media requests

Events

  • Timeline cues — React to SCTE-35 events in a DASH manifest and EXT-X-DATERANGE tags in HLS
  • Player events — Log HTML5 media events and PRESTOplay events, listen once, and remove a listener
  • Error handling — Error event and rejected Promise, error category and severity, and network retry attempts

Casting

  • Chromecast sender — Cast the player content to a Chromecast device and control it
  • Chromecast receiver — Custom Web Receiver app with a queue, track info, and custom messages for the sender
  • AirPlay — Play HLS on an AirPlay device from Safari

Analytics

  • Conviva analytics — Basic DASH playback with Conviva analytics enabled
  • Mux Data analytics — Basic DASH playback with Mux Data enabled
  • Broadpeak analytics and SSAI — Broadpeak SmartLib analytics and server-side ad tracking with an ad countdown and skip button (needs a Broadpeak stream)
  • NPAW v7 analytics — Basic DASH playback with NPAW v7 analytics enabled

Audio

  • Audio player — Audio-only HLS playback with an audio element and custom controls
