# prestoplay-web-code-samples

This repository contains code samples of how to use PRESTOplay Web SDK.
The examples are framework-independent simple HTML files.

## How to run

1. Clone this repository.
2. Run `npm install`.
3. Run HTTP server.
    - e.g., if you want to use `http-server` package:
      1. install it first: `npm install --global http-server`
      2. run the server: `http-server -c-1`
4. In your browser, go to examples folder and explore sample files.
